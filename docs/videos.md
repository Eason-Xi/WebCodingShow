# 影像创作

- 展示页：`/videos`；后台入口：`/admin/videos`；录入：`/admin/videos/new`。
- 沿用 Project 数据，不需要新增数据库表或迁移。所有已发布、带有有效 B 站视频链接的作品会进入影像集合；草稿不会公开。
- 优先采用「视频演示链接」，其次采用「线上 URL」。支持 B 站 BV / av 详情页与 b23.tv 分享链接，不收录主页、非 B 站地址或伪装域名。
- 使用作品封面；封面无法加载时显示影像占位画面。访客点击整个卡片，在新标签页进入 B 站，沿用视频点击统计。
- 使用原有作品排序；页头优先展示精选作品，否则展示列表首项。搜索支持标题、简介和标签，多分类时提供分类筛选。
- 后台可上传封面，也可尝试智能提取网页信息。B 站限制读取时请手动填写标题和封面。

## 指定测试视频

用户提供：https://www.bilibili.com/video/BV1t7HN6QErA/

标题与封面来自该公开视频，创作者为「方阿成」。封面保存在 `public/images/videos/BV1t7HN6QErA.jpg`。

对需要演示数据的数据库，运行 `npx tsx scripts/import-video-sample.ts`。脚本连接当前环境配置的数据库，若测试视频已存在则保留现有内容。部署到其他环境时，需要在对应数据库录入视频或运行此脚本；数据库内容不随 Git 自动同步。
